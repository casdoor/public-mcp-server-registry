## Adding a new server

1. Fork this repository
2. Add your entry to [`registry.json`](registry.json):

```json
{
  "id": "your-server-id",
  "name": "Your Server Name",
  "description": "One-line description of what this server does.",
  "category": "productivity",
  "website": "https://your-website.com",
  "endpoint": "wss://your-endpoint.example.com"
}
```

3. Open a Pull Request — the website updates automatically on merge.

For website development and deployment docs, see [WEBSITE.md](WEBSITE.md).
